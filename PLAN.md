# Faceless Instagram Agent — Build Plan v0.2 (zero paid-plan dependencies)

**Goal:** Run a faceless Instagram account per brand with AI "employees"; humans only press Approve / Revise / Reject in Discord. Multi-brand by folder. No paid SaaS plans.

**Only variable cost:** LLM tokens (Anthropic API, pay-as-you-go, est. ₹300–1,200/month at 5 posts/week). Optional zero-cost fallback: Gemini free tier or a local model via Ollama (lower quality). Everything else below is free tier or open source.

## Architecture
| Layer | Choice | Cost | Why |
|---|---|---|---|
| Brain | Claude API (one prompt per employee) | tokens only | quality; prompts live in `agents/` |
| Scheduler + runtime | **GitHub Actions** cron (public or private repo) | free (2,000 min/mo private; unlimited public) | your existing pattern; no server to keep alive |
| System of record | the repo itself: `brands/<id>/queue/*.json`, `publish_log.jsonl`, `insights.md` committed by Actions | free | auditable, versioned, multi-brand by folder |
| Office / approvals | Discord: webhooks post review cards **with buttons**; a tiny **Cloudflare Worker** (free tier, no card) receives button clicks and calls `workflow_dispatch` on GitHub | free | no always-on bot process needed |
| Brand rules | `brand.json`, `products.json` | free | deterministic |
| Layout | **HTML/CSS templates** in repo → **Playwright** renders PNG (feed) and frames; **ffmpeg** assembles reels (Ken Burns over photos + text overlays) | free | brand fidelity via CSS variables; Guardian can verify literally |
| Imagery | real product photos + brand-style **flat-vector SVG illustrations generated by Claude** (matches the jar-label art) + free stock via **Pexels/Unsplash API** for ambience | free | no generative-image spend; no AI packaging |
| Media hosting | **GitHub Pages** on the same repo (`/public/media/…`) — Instagram fetches from public URLs | free | no bucket, no card |
| Publish + insights | Instagram Graph API (Business account + FB Page) | free | official |
| Local dev | Python 3.12, Playwright, ffmpeg, Claude Code | free | |

Canva: not in the pipeline. Optional free-tier brand kit for human reference only.

## Flow
1. **Sunday 06:00 KST — Strategist job** (Actions cron): reads brand.json + insights.md + publish_log → writes `queue/plan-<week>.json` → posts summary to `#calendar` via webhook with buttons **Approve plan / Revise**.
2. **On plan approval** (button → Worker → `workflow_dispatch: produce`): **Producer** builds each slot: caption → picks template → picks real photo or asks Claude for an SVG illustration → renders PNG/MP4 → commits to `/public/media/<slot_id>/` → **Guardian** runs → review card to `#review` (preview image, caption, time, 🛡️ stamp) with buttons **Approve / Revise / Reject**.
3. **Revise**: Worker opens a Discord modal for the note → dispatch `produce` with `slot_id + note` → new version in same thread.
4. **Approve** (allow-listed Discord user IDs only): Worker writes `queue/<slot_id>.approved.json` (content hash frozen) via GitHub API.
5. **Every 30 min — Publisher job**: publishes any approved slot whose time has arrived (container → publish → permalink) → appends `publish_log.jsonl` → `#published`.
6. **Daily 05:00 — Analyst job**: 48-h stats per post → `#insights`; Sunday rollup → `insights.md`; human replies collected via a `/note` slash command handled by the Worker.
7. **`#ops`**: any job failure posts the Actions run link.
